Portfolio Studio

Add or edit projects without touching the HTML. Everything runs in your browser; nothing is uploaded anywhere. At the end you download a package and drop it on GitHub.

1 · Load your current projects.js

Recommended: load the projects.js that is currently on your site, so the new package contains all your projects. Without it the package will contain only the project you build here.

2 · Project details

3 · Screenshots

Drop images here or click to choose (PNG, JPG, WebP). The first image is the main one.

Images are resized (full 1600 px, thumbnail 640 px) and converted to WebP in your browser. Caption = text shown in the gallery; short label = optional shorter text under thumbnails.

4 · Build

Package content: projects.js (all projects) and assets/<project-id>/ with the new images. Upload both to your site repository (same folder as index.html), replacing the old projects.js.
